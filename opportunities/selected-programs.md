# Selected White-Hat Bounty Programs for Read-Only Triage

Based on the criteria outlined in the white-hat start list, the following two programs have been selected for read-only triage:

1. **Immunefi - dYdX**: 
   - Clear smart contract scope: Yes
   - Public GitHub repo: https://github.com/dYdXprotocol/dydx-v3
   - Deployed contract addresses: Available on Etherscan
   - Explicit safe harbor: Yes, outlined in the Immunefi terms
   - Clear reward table: Yes, outlined on the Immunefi website
   - Simple protocol mechanics: Yes, primarily focused on decentralized exchange
   - No requirement to attack live funds: Yes, testing can be done on a local fork/testnet environment

   - Clear reward table: Yes, outlined on the HackenProof website
   - Simple protocol mechanics: Yes, primarily focused on decentralized finance
   - No requirement to attack live funds: Yes, testing can be done on a local fork/testnet environment
