Application info: https://solana.org/grants-funding

Current fit: **not ready yet**.

Reason: Solana Foundation grants prioritize public goods for the Solana ecosystem and ask why the project is only possible or especially useful on Solana. On-chain Risk Scanner is currently EVM-focused, so applying now would be weak.

## How To Become Eligible

Build an SVM/Solana module:

- account/program metadata scanner,
- upgrade authority detection for Solana programs,
- known-token and token-account risk summaries,
- program deployment/update timeline,
- public reports for Solana programs.

## Proposed Solana Pitch

Solana Program Risk Scanner would provide read-only public-good tooling that helps users and developers understand program upgrade authority, account ownership, and deployment/update history before integrating with Solana programs.
