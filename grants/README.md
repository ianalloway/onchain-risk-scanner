# Grant Submission Pack

This folder contains application-ready materials for On-chain Risk Scanner.

Public repo: https://github.com/ianalloway/onchain-risk-scanner

## Priority Order

1. **Base Builder Grants nomination** - strongest immediate fit because the project is already live, scans Base, and Base grants are retroactive.
2. **Ethereum Foundation ESP Glamsterdam Grants Round** - strongest formal grant fit if framed as impact-analysis tooling for Glamsterdam readiness.
3. **Gitcoin GG24 Developer Tooling & Infrastructure / Interop** - good community funding fit after adding a short demo and stronger public metrics.
4. **Starknet Seed Grants** - later fit only after adding Starknet/Cairo support or a Starknet-specific proof of concept.
5. **Solana Foundation Grants** - later fit only after adding Solana/SVM support; current EVM-only code is not a clean fit.

## Sensitive Fields Needed From Ian

- Email address for grant forms
- X/Twitter handle
- Farcaster handle or channel
- Country and timezone
- Whether to use personal name, a team name, or `N/A` for organization
- 1-minute demo video URL for Base
- Any prior grant/funding history
- Preferred payout wallet, if requested by a platform

## Public-Safety Rule

Do not commit tax forms, KYC documents, private wallet keys, seed phrases, personal ID, or non-public grant portal screenshots.
